# Release `v0.1.0`

## Summary

Initial release of `admission-engine` (`service-template` v0.1.0), establishing the Sans-I/O admission state machine, Expand/Contract `v1 <-> v2` snapshot codec, atomic `--state-out` checkpointing, `platform.domain-config/v1` config envelope interoperability, path-stripped reproducible `release-manifest.json` packaging, and SLSA build provenance pipeline.

## Compatibility Descriptor (`schema/compatibility.json`)

| Field | Value | Notes |
| :--- | :--- | :--- |
| `schema` | `service.compatibility/v1` | Shared contract consumed by `platform-template` |
| `service_name` | `admission-engine` | Service binary & artifact stem |
| `config_schema_version` | `1` | `EngineConfig` (`window_ms`, `max_units_per_window`, `max_burst_units`, `state_write_version`) |
| `state_format_version` | `2` | Current `ADMSNAP\0` snapshot format (`audit_epoch` aware) |
| `min_readable_state_format` | `1` | Reads both `v1` and `v2` snapshots |
| `oldest_writable_state_format` | `1` | Can emit `v1` bridge snapshots during mixed-writer rollouts |
| `transition_mode` | `expand` | Mixed-version Expand window |
| `preserved_state_fields` | `["window_epoch_ms", "consumed_units", "last_sequence"]` | Lossless across `v2 -> v1 -> v2` |
| `version_specific_defaults` | `{"v1_to_v2_audit_epoch": 1}` | Deterministic default when upgrading `v1` snapshots |

## Release Channels, Lineage & Handoff

- **Lineage rules**: `vX.Y.0` (and pre-releases `-alpha.N` / `-beta.N` / `-rc.N`) cut from `origin/main` or `origin/release/X.Y`; patch releases `vX.Y.Z` (`Z > 0`) cut strictly from `origin/release/X.Y`.
- **Environment separation**: `main-release` gates PR promotions onto `main`/`release/*`, while `stable-publish` gates stable `vX.Y.Z` GitHub Release publication.
- **Attested assets**: `admission-engine-v0.1.0-<target>.tar.gz`, `compatibility.json`, `release-manifest.json`, and `SHA256SUMS`.
